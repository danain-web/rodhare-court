วิธีติดตั้งและเข้าใช้งาน Barbie Sports Arena

ทำตามลำดับ 1 → 6 · ขั้นที่ 1–3 ทำครั้งเดียวต่อเครื่อง · ใช้เวลาประมาณ 30–60 นาที (ส่วนใหญ่คือติดตั้ง Oracle)

เคยติดตั้งครบแล้ว? ข้ามไปขั้นที่ 4 ได้เลย: ดับเบิลคลิก reset_demo.bat แล้ว start_demo.bat

1. ติดตั้งโปรแกรม (ครั้งเดียว)

โปรแกรมดาวน์โหลดหมายเหตุ
Node.js v20 ขึ้นไปnodejs.org → ปุ่ม LTSกด Next ไปเรื่อย ๆ ได้เลย
Oracle Database 21c Express Edition (XE)oracle.com → XE Downloads → Windows x64ตอนติดตั้งจะให้ตั้งรหัสผ่าน จดไว้ให้ดี (ใช้กับ user system)
Oracle SQL Developeroracle.com → SQL Developer → Windows 64-bit with JDKไม่ต้องติดตั้ง แตก zip แล้วเปิด sqldeveloper.exe
เช็คว่า Node.js ติดตั้งแล้ว: เปิด Command Prompt พิมพ์ node -v ต้องขึ้น v20 ขึ้นไป

2. แตกไฟล์ zip

  1. คลิกขวาที่ barbie_sports_arena.zip → Extract All... → Extract
  2. จะได้โฟลเดอร์ rodhare court ข้างในมีไฟล์ start_demo.bat, reset_demo.bat และโฟลเดอร์ backend, frontend, database
ห้ามรันจากในไฟล์ zip โดยตรง ต้องแตกไฟล์ออกมาก่อน

3. สร้าง user ฐานข้อมูล (ครั้งเดียว)

  1. เปิด SQL Developer → กดปุ่ม + สีเขียวมุมซ้ายบน (New Connection)
  2. กรอกตามนี้แล้วกด Test ต้องขึ้น Status: Success แล้วกด Connect
    Namesystem (ตั้งอะไรก็ได้)
    Usernamesystem
    Passwordรหัสที่ตั้งตอนติดตั้ง Oracle
    Hostname / Portlocalhost / 1521
    Service name (เลือกช่องนี้ ไม่ใช่ SID)XEPDB1
  3. File → Open → เลือก database\create_user.sql → กด F5 (Run Script)
  4. ต้องขึ้น User RODHARE created และ Grant succeeded
ถ้าขึ้น error ว่า user มีอยู่แล้ว (ORA-01920) แปลว่าเคยสร้างไว้แล้ว ข้ามไปขั้นต่อไปได้

4. สร้างตารางและข้อมูลตั้งต้น

  1. ดับเบิลคลิก reset_demo.bat
  2. พิมพ์ Y แล้วกด Enter → รอประมาณ 30 วินาที
  3. ต้องขึ้นผลแบบนี้: 
    Invalid objects : 0
Users           : 5
Courts          : 6
Bookings        : 0
ถ้าขึ้นว่าหา sqlplus ไม่เจอ ให้ทำใน SQL Developer แทน: สร้าง connection ใหม่ username rodhare รหัส rodhare123 service XEPDB1 แล้วเปิดไฟล์ในโฟลเดอร์ database กด F5 ทีละไฟล์ตามลำดับ schema.sql → constraints.sql → views.sql → seed.sql

5. เปิดระบบ

  1. ดับเบิลคลิก start_demo.bat
  2. ครั้งแรก จะติดตั้งโปรแกรมเสริม (npm install) ประมาณ 1–3 นาที ต้องต่ออินเทอร์เน็ต รอจนเสร็จ
  3. จะมีหน้าต่างสีดำ 2 อัน (Backend และ Frontend) ห้ามปิด ระหว่างใช้งาน
  4. เบราว์เซอร์จะเปิดหน้า http://localhost:3000/health ให้เอง ต้องขึ้นว่า เชื่อมต่อฐานข้อมูลแล้ว

6. เข้าใช้งาน

เปิด http://localhost:3000/login แล้วกดปุ่มบัญชีในกล่อง "บัญชีทดสอบ" ได้เลย

Usernameบทบาทใช้ดูอะไร
customer1ลูกค้า (บุคคลภายนอก)ค้นหาสนาม จองสนาม ส่งสลิป ใบเสร็จ
customer2ลูกค้า (นักศึกษา ลด 10%)ใช้ทดสอบจองซ้อนเวลา
staff1พนักงานสนามตรวจสลิป เช็คอิน ยืม/คืนอุปกรณ์ อนุมัติคืนเงิน
admin1ผู้ดูแลระบบจัดการสนาม ราคา อุปกรณ์ Audit Log
exec1ผู้บริหารแดชบอร์ดรายได้และ Peak Hours

รหัสผ่านทุกบัญชี: Password123!

ขั้นตอน Demo ทีละคลิก: เปิดไฟล์ DEMO_DAY_CHECKLIST.html

ปิดระบบ / เปิดครั้งต่อไป

  • ปิด: ปิดหน้าต่างสีดำ 2 อัน
  • เปิดครั้งต่อไป: ดับเบิลคลิก start_demo.bat อย่างเดียว (ไม่ต้องทำขั้นที่ 1–4 ซ้ำ)
  • ล้างข้อมูลที่ซ้อมไว้: ดับเบิลคลิก reset_demo.bat แล้วพิมพ์ Y

แก้ปัญหาที่พบบ่อย

อาการวิธีแก้
หน้า health ขึ้นว่า ไม่เชื่อมต่อฐานข้อมูล 1) กด Windows → พิมพ์ services → เช็คว่า OracleServiceXE และ OracleOraDB21Home1TNSListener เป็น Running (ถ้าไม่ คลิกขวา → Start)
2) เปิดไฟล์ backend\.env ด้วย Notepad ดูบรรทัด DB_CONNECT_STRING=localhost:1521/XEPDB1 ถ้าสร้าง user ไว้ใน service xe ให้แก้เป็น localhost:1521/xe แล้วปิดเปิด start_demo.bat ใหม่
reset_demo.bat ขึ้น ORA-01017 invalid username/passwordยังไม่ได้ทำขั้นที่ 3 หรือทำใน service คนละตัว (ดูข้อ 2 ด้านบน)
หน้าเว็บไม่ขึ้น / ขึ้น "This site can't be reached"หน้าต่างสีดำถูกปิด หรือยัง npm install ไม่เสร็จ → ปิดหน้าต่างสีดำทั้งหมด แล้วดับเบิลคลิก start_demo.bat ใหม่
หน้าต่างสีดำขึ้น 'npm' is not recognizedยังไม่ได้ติดตั้ง Node.js หรือติดตั้งแล้วยังไม่ได้รีสตาร์ทเครื่อง
ขึ้น port 3000/5000 already in useมีระบบเปิดค้างอยู่แล้ว → ปิดหน้าต่างสีดำเก่าทั้งหมดก่อน หรือรีสตาร์ทเครื่อง
ภาษาไทยใน SQL Developer ขึ้นเป็น ?Tools → Preferences → Environment → Encoding → UTF-8 แล้วเปิดไฟล์ใหม่
รูปสนาม / QR Code ไม่ขึ้นไม่มีอินเทอร์เน็ต (รูปและ QR โหลดจากเว็บภายนอก) ระบบอื่นยังใช้งานได้ปกติ
