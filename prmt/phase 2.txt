
# PHASE 2
## Authentication + Authorization + RBAC

ต่อจาก Phase 1

เป้าหมายคือสร้างระบบ Login ที่ใช้งานจริงและแยกสิทธิ์ตาม Role

---

## 1. Login

สร้าง:

POST /api/auth/login

รับ:

email/username
password

ตรวจสอบ:

USERS
USER_ROLES
ROLES

Password ต้อง Hash

ห้ามเก็บ Password Plain Text

---

## 2. Authentication

หลัง Login สำเร็จ ให้สร้าง Authentication Session

รองรับ:

- Token
- Expiration
- Logout
- Session Revocation

ถ้าใช้ JWT:

Access Token ต้องมี:

user_id
role
expiration

---

## 3. Protected Route

สร้าง Middleware:

requireAuth

ตรวจสอบ:

- Token
- User
- Session
- Expiration
- Revoked Session

---

## 4. Role Middleware

สร้าง:

requireRole('CUSTOMER')
requireRole('STAFF')
requireRole('ADMIN')
requireRole('EXECUTIVE')

---

## 5. Authorization Matrix

CUSTOMER:

สามารถ:
- ดูสนาม
- จอง
- ดู Booking ของตัวเอง
- Payment
- Notification

STAFF:

สามารถ:
- ตรวจ Payment
- Check-in
- Borrow/Return Equipment

ADMIN:

สามารถ:
- User Management
- Court Management
- Pricing
- Promotion
- Equipment

EXECUTIVE:

สามารถ:
- Dashboard
- Reports

---

## 6. Frontend

สร้าง:

/login
/dashboard
/profile

ถ้าไม่ได้ Login:

Redirect /login

ถ้า CUSTOMER:

แสดง Customer Dashboard

ถ้า STAFF:

แสดง Staff Dashboard

ถ้า ADMIN:

แสดง Admin Dashboard

ถ้า EXECUTIVE:

แสดง Executive Dashboard

---

## 7. Security

ต้องป้องกัน:

- Access Admin API ด้วย Customer
- Access User อื่น
- Expired Token
- Revoked Session
- Invalid Password
- Brute Force เบื้องต้น

---

## 8. Test

ทดสอบ:

1. Login สำเร็จ
2. Password ผิด
3. User ไม่มี
4. Token หมดอายุ
5. Logout
6. CUSTOMER เปิด ADMIN API
7. STAFF เปิด ADMIN API
8. ADMIN เปิด Admin API

ทุกกรณีต้องได้ HTTP Status ที่ถูกต้อง
