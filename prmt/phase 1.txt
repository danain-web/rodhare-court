
# PHASE 1
## Project Architecture + Database Connection

เริ่ม Phase 1 ของระบบ Online Sports Court Booking System

เป้าหมายของ Phase นี้คือเตรียมระบบให้พร้อมสำหรับการพัฒนาจริง

ห้ามสร้าง Feature Booking เต็มรูปแบบใน Phase นี้

---

## STEP 1 — ตรวจสอบ Project

ตรวจสอบ:

- Folder Structure
- package.json
- Frontend
- Backend
- Database
- Environment Variables
- Existing API
- Existing Components

ก่อนแก้ไข ให้สรุป:

1. Project ใช้ Technology อะไร
2. Frontend อยู่ที่ไหน
3. Backend อยู่ที่ไหน
4. Database ใช้อะไร
5. มี API อะไรแล้ว
6. มี Authentication หรือยัง

ห้ามเดา หากไม่พบให้ระบุว่าไม่พบ

## STEP 3 — Database Connection

เชื่อมต่อ Oracle Database จริง

ใช้ Environment Variables เช่น:

DB_HOST
DB_PORT
DB_SERVICE
DB_USER
DB_PASSWORD

ห้าม Hardcode Password

สร้าง Database Connection Pool

ต้องมี:

- Connection
- Release
- Error Handling
- Pool Configuration

## STEP 5 — Health Check

สร้าง:

GET /api/health

Response:

{
  "status": "ok",
  "database": "connected"
}

ถ้า Database เชื่อมไม่ได้:

{
  "status": "error",
  "database": "disconnected"
}
