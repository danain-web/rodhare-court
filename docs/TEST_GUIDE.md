# คู่มือทดสอบระบบด้วยมือ (Manual Test Guide)

ใช้ทดสอบฝั่งผู้ใช้ทุกจุดก่อนส่งงาน ทำตามลำดับหัวข้อ ติ๊ก ☐ เป็น ✅ เมื่อผ่าน หรือเขียนหมายเหตุเมื่อไม่ผ่าน

> เทสต์อัตโนมัติ (215 ข้อ) ครอบคลุมฝั่ง API แล้ว คู่มือนี้เน้นสิ่งที่ผู้ใช้เห็นและกดในหน้าเว็บ ซึ่งเทสต์อัตโนมัติไม่ครอบคลุม

## 0. เตรียมการก่อนทดสอบ

### 0.1 บัญชีทดสอบ (รหัสผ่านทุกบัญชี `Password123!`)

| Username | บทบาท | ใช้ทดสอบ |
|---|---|---|
| `customer1` | ลูกค้า (บุคคลภายนอก) | จอง ชำระเงิน ยกเลิก ค่าปรับ |
| `customer2` | ลูกค้า (นักศึกษา ลด 10%) | ส่วนลดสมาชิก จองซ้อนช่วงเวลา |
| `staff1` | พนักงาน | ตรวจสลิป เช็คอิน ยืม-คืนอุปกรณ์ คืนเงิน |
| `admin1` | ผู้ดูแลระบบ | จัดการข้อมูลหลัก ผู้ใช้ สิทธิ์ ตั้งค่า |
| `exec1` | ผู้บริหาร | ภาพรวมและรายงาน (ดูอย่างเดียว) |

### 0.2 ไฟล์และข้อมูลที่ต้องเตรียม
- สลิปตัวอย่างในโฟลเดอร์ `demo_slips/` (เช่น `slip_210_DEMO0001.png`)
- ไฟล์ทดสอบความผิดพลาด: ไฟล์ `.pdf`, ไฟล์ `.txt` ที่เปลี่ยนนามสกุลเป็น `.png`, ไฟล์รูปใหญ่กว่า 5 MB
- โค้ดโปรโมชั่น: `WELCOME10` (ลด 10%), `DISCOUNT50` (ลด 50 บาท เมื่อจอง 2 ชม.ขึ้นไป), `MORNING20` (ลด 20% เฉพาะ 08:00-12:00)
- อีเมลจริงที่รับเมลได้ 1 บัญชี (สำหรับทดสอบลืมรหัสผ่าน) และบัญชี Google สำหรับทดสอบ Google login
- เบราว์เซอร์ 2 ตัว หรือหน้าต่างปกติ + Incognito (สำหรับทดสอบสองผู้ใช้พร้อมกัน)

### 0.3 โหมดชำระเงิน — ตรวจก่อนเริ่ม
ระบบมี 2 โหมด ผลการทดสอบหมวด 2.5 ต่างกัน:

| โหมด | ตั้งค่าที่ Render (`PAYMENT_DEMO_MODE`) | พฤติกรรม |
|---|---|---|
| ตรวจสลิปโดยพนักงาน (ค่าเริ่มต้น production) | `false` หรือไม่ตั้ง | ส่งสลิปแล้วรอพนักงานอนุมัติ |
| สาธิต | `true` | สลิปที่ยอดตรงอนุมัติทันที มี QR จำลอง |

ทดสอบหมวด 2.5 ให้ครบทั้งสองโหมด (เปลี่ยนค่าแล้วรอ Render deploy เสร็จ) และเปลี่ยนกลับเป็น `false` หลังทดสอบ

### 0.4 ค่าที่ควรจดไว้ก่อน
เข้า `admin1` → **ตั้งค่าระบบ** จดค่าช่วงเช็คอิน (ก่อนเริ่ม/หลังเริ่มกี่นาที) และเวลาแจ้งเตือน เพราะผลทดสอบเช็คอิน/ไม่มาใช้บริการขึ้นกับค่านี้

### 0.5 หมายเหตุ
- Render ฟรีหลับเมื่อไม่มีคนใช้ เปิดเว็บรอ 30-60 วินาทีก่อนเริ่ม
- ทดสอบแต่ละข้อด้วยข้อมูลใหม่ที่ไม่ซ้ำ (วันที่/เวลาจองต่างกัน) เพื่อไม่ชนกันเอง
- ข้อที่ต้องจองหลายรายการ ให้เลือกวันล่วงหน้าคนละวัน (จองได้ไม่เกิน 30 วัน)
